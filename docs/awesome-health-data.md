# Awesome Health Data

Open source projects we looked at or forked while building PLUGIN.
The forks themselves were removed from the organisation, so these links point to the original projects.

## FHIR and Dutch information standards

- [Nictiz-R4-zib2020](https://github.com/Nictiz/Nictiz-R4-zib2020): NL package of FHIR R4 conformance resources for zib release 2020.
- [zorgviewer-ig](https://github.com/RIVO-Noord/zorgviewer-ig): Zorgviewer FHIR Implementation Guide.
- [FHIRPathMappingLanguage](https://github.com/beda-software/FHIRPathMappingLanguage): FHIRPath based mapping language by Beda Software.
- [fhir2omop](https://github.com/lampadephoros/fhir2omop): FHIR R4 to OMOP CDM v5.4 mapping specification and ELT runtime.

## OMOP and vocabulary mapping

- [Ariadne](https://github.com/OHDSI/Ariadne): Python toolkit for mapping source terminologies to standard concepts in the OHDSI Vocabulary.
- [Eos](https://github.com/SevKohler/Eos): ETL engine to transform openEHR into OMOP.
- [OMOCL](https://github.com/SevKohler/OMOCL): Configuration language used by Eos.
- [concept-based-mapping](https://github.com/sxzhang1201/concept-based-mapping): Concept based terminology mapping.
- [hutch-bunny](https://github.com/Health-Informatics-UoN/hutch-bunny): Cohort discovery task resolver.

## Data stations and data curation

- [data-station-specification](https://github.com/Health-RI/data-station-specification): Specification of composable data stations by Health-RI.
- [data-curation-tool](https://github.com/fair4health/data-curation-tool): FAIR4Health data curation and validation tool.

## Integration and tooling

- [ViscoSuite](https://git.viscosiety.com/public-applications/viscosuite/): Integration suite with ViscoLink (Frank!Framework), ViscoStore (HAPI FHIR server) and ViscoRunner.
- [frankframework](https://github.com/frankframework/frankframework): Stateless integration framework for exchanging messages between systems.
- [docling-core](https://github.com/docling-project/docling-core): Docling core data types and transformations.
- [skills](https://github.com/dagster-io/skills): Collection of AI skills for working with Dagster.
- [nyctea](https://github.com/yannick-vinkesteijn/nyctea): Polars validation package.
